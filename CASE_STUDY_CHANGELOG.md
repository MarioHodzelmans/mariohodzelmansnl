# AI-Native Website - Development Log

This file documents meaningful changes to the architecture and capabilities of mariohodzelmans.nl.

It is not intended to record every design adjustment or minor code change. Only changes that materially affect the case study, development workflow or underlying system are included.

## Current Status

**LIVE - Continuously evolving**

## Current Architecture

- AI-assisted development with ChatGPT and Claude
- Next.js, React and TypeScript application
- Puck visual editing layer
- Payload CMS content management
- PostgreSQL database infrastructure via Supabase
- GitHub as source of truth
- Vercel deployment and hosting

## Development Log

### 2026-08 - Living case study published

The website development workflow is documented as an ongoing AI-native case rather than a time-sensitive blog post. The case is available at `/cases/ai-native-website` and is designed to evolve with the system.

### 2026-08 - Puck visual editing

Puck was introduced as a visual editing layer for React components. This adds a third way of interacting with the website alongside conversational AI and direct code development.

## Architecture Principle

**Human Intent -> AI Assistance -> Structured Systems -> Production**

Specific tools may change over time. The architecture is designed so individual technologies can evolve without changing the fundamental philosophy of the project.
